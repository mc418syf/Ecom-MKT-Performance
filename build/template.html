Each dated send whose name mentions a vendor (e.g. adidas, Jordan, Salomon). Compares that vendor's net sales on the send day and the next two days with the three days before. All-vendor lift is shown when no brand is named. A heuristic, not proof.

Method and data lineage
Weekly refresh
Drop the new daily exports into data/channels/, data/campaigns/ and data/product/ (date range in each file name), then run python3 build/build.py. A newer file replaces any dates it repeats. Weeks start Sunday; times are America/Vancouver.
